# เก็บตัวไฟล์หลักฐานในฐานข้อมูล

เจ้าของงานเลือกเมื่อ 28 พ.ย. 2569 ให้เก็บเนื้อไฟล์หลักฐานใน MySQL เพื่อให้สำรองและย้ายข้อมูลทั้งระบบได้ที่เดียว
รายการงานกับไฟล์จึงบันทึกพร้อมกันใน transaction เดียว ยอมรับว่าฐานข้อมูลและไฟล์สำรองจะโตเร็ว

## Considered Options

- **โฟลเดอร์บนเครื่อง backend** ฐานข้อมูลเก็บแค่ตำแหน่ง ฐานข้อมูลเล็ก แต่ต้องสำรองสองที่และกันไม่ให้ข้อมูลสองฝั่งไม่ตรงกัน
- **บริการเก็บไฟล์บนคลาวด์** ต้องมีบัญชีและอาจมีค่าใช้จ่าย เกินความจำเป็นของงานต้นแบบ

## Consequences

- เซิร์ฟเวอร์ฐานข้อมูลต้องตั้ง `max_allowed_packet` อย่างน้อย 16M ค่าตั้งต้นของ MariaDB ใน XAMPP (1M) ไม่พอสำหรับไฟล์ 5 MB
- ไฟล์ที่ถูกเอาออกจากรายการยังเก็บไว้ดูประวัติ จึงยังกินพื้นที่
