# Design pattern ของระบบ

อ้างอิงภาพ "Design System & มาตรฐานส่วนประกอบ UI" ที่เจ้าของงานส่งมา และข้อสรุปที่ยืนยันเมื่อ 27 พ.ย. 2569
ปรับหน้าจอตามไฟล์นี้แล้วเมื่อ 27 พ.ย. 2569 หน้าจอใหม่ให้ทำตามไฟล์นี้

ช่อง **ที่มา** บอกว่าค่านั้นมาจากไหน ทุกข้อยืนยันแล้ว

| ที่มา | ความหมาย |
|---|---|
| ภาพ | อยู่ในภาพ design system |
| ยืนยัน | ภาพไม่ได้กำหนด หรือปรับจากภาพ เจ้าของงานยืนยันแล้ว |

## 1. สี

ใช้ค่า hex ในไฟล์นี้ และกำหนดเป็น token ใน `app/assets/css/main.css`
สีชื่อเดียวกันของ Tailwind v4 (เช่น `indigo-600`) ให้ค่าต่างจากนี้เล็กน้อย ชื่อในวงเล็บใช้บอกเฉดเท่านั้น

| Token | ค่า | ใช้กับ | ที่มา |
|---|---|---|---|
| sidebar | `#101233` (Deep Navy) | แถบเมนูหลักทุกพอร์ทัล | ภาพ |
| primary | `#4F46E5` (indigo-600) | ปุ่มหลัก ลิงก์ เมนูที่เลือก กรอบช่องที่กำลังกรอก | ค่าสีจากภาพ การใช้งานยืนยัน |
| primary-hover | `#4338CA` (indigo-700) | ปุ่มหลักตอนชี้เมาส์ | ยืนยัน |
| start | `#2563EB` (blue-600) | ปุ่มเริ่มทำงาน | ภาพ |
| success | `#047857` (emerald-700) | ปุ่มทำงานเสร็จ | ยืนยัน (เข้มกว่าภาพเพื่อให้อ่านชัด) |
| danger | `#DC2626` (red-600) | ลบ ข้อความผิดพลาด | ยืนยัน |
| warning-action | `#C2410C` (orange-700) | ส่งกลับแก้ไข | ยืนยัน |
| line | `#E2E8F0` (slate-200) | เส้นขอบ เส้นคั่น พื้นปุ่มที่กดไม่ได้ | ค่าสีจากภาพ การใช้งานยืนยัน |
| page | `#F8FAFC` (slate-50) | พื้นหลังหน้า | ยืนยัน |
| surface | `#FFFFFF` | การ์ด ตาราง หน้าต่าง | ภาพ |
| text | `#0F172A` (slate-900) | หัวข้อและข้อความหลัก | ภาพ (ประมาณ) |
| text-muted | `#64748B` (slate-500) | คำอธิบายและข้อความรอง | ยืนยัน |

ตัวอักษรขาวบน primary, start, success, danger และ warning-action ผ่านเกณฑ์ความต่างสี WCAG AA (อย่างน้อย 4.5:1)

## 2. ตัวอักษร

ฟอนต์ **Bai Jamjuree** (ยืนยัน)

| ระดับ | ขนาด | น้ำหนัก | ที่มา |
|---|---|---|---|
| หัวข้อหน้า (Page Title) | 24px | 700 | ภาพ |
| หัวข้อการ์ด (Card Title) | 16px | 700 | ภาพ |
| เนื้อหาและตาราง | 12–14px | 400–600 | ยืนยัน |
| ข้อความรอง ป้ายสถานะ | 10–11px | 500–600 | ยืนยัน |

## 3. วันที่และเวลา

ปีเป็น พ.ศ. และเวลาเป็น 24 ชั่วโมง

| กรณี | รูปแบบ | ตัวอย่าง | ที่มา |
|---|---|---|---|
| วันที่ที่แสดงผล | `วว-เดือนย่อ-ปปปป` | `26-พ.ย.-2569` | ยืนยัน |
| เวลา | `HH:mm น.` | `08:45 น.` | ภาพ |
| วันที่และเวลา | `วันที่ • เวลา` | `23-พ.ย.-2569 • 09:22 น.` | ภาพ ปรับตามรูปแบบวันที่ที่ยืนยัน |
| ช่วงเวลา | `HH:mm–HH:mm น.` | `09:00–12:00 น.` | ยืนยัน |
| ช่วงวันที่ | `วันที่ – วันที่` | `23-พ.ย.-2569 – 29-พ.ย.-2569` | ยืนยัน |
| ที่แคบ เช่น หัวคอลัมน์ปฏิทิน | `วัน วว-เดือนย่อ` | `จ. 23-พ.ย.` | ยืนยัน |
| ช่องกรอกวันที่ | พิมพ์เป็นตัวเลข `วว-ดด-ปปปป` | `26-11-2569` | ยืนยัน |
| ช่องกรอกเวลา | placeholder `00:00` | | ยืนยัน |

ป้ายเวลาที่ต้องการให้เด่น: พื้น `#EFF6FF` (blue-50) ขอบ `#BFDBFE` (blue-200) ตัวอักษร `#1D4ED8` (blue-700) — ภาพ

ข้อมูลที่รับส่งกับ backend ยังเป็น `YYYY-MM-DD` และ `HH:MM` ตาม [api-contract.md](api-contract.md)

## 4. ป้ายสถานะ

รูปทรงเป็นแคปซูล (มุมโค้งเต็ม) ตัวอักษรหนา สีตัวอักษรอ่านจากภาพจึงเป็นค่าประมาณ

### สถานะความคืบหน้าของงาน

| สถานะ | ค่าในระบบ | พื้น | ตัวอักษร | ที่มา |
|---|---|---|---|---|
| รอดำเนินการ | `pending` | `#E2E8F0` (slate-200) | `#475569` (slate-600) | ภาพ |
| กำลังดำเนินการ | `in_progress` | `#DBEAFE` (blue-100) | `#1D4ED8` (blue-700) | ภาพ |
| เสร็จสิ้น | `done` | `#D1FAE5` (emerald-100) | `#047857` (emerald-700) | ภาพ |

### สถานะการตรวจสอบ

| สถานะ | ค่าในระบบ | พื้น | ตัวอักษร | ที่มา |
|---|---|---|---|---|
| ฉบับร่าง | `draft` | `#F1F5F9` (slate-100) ขอบ `#E2E8F0` | `#475569` | ภาพ |
| รอตรวจ | `submitted` | `#FEF3C7` (amber-100) | `#B45309` (amber-700) | สีจากภาพ ชื่อยืนยัน |
| อนุมัติแล้ว | `approved` | `#D1FAE5` (emerald-100) | `#047857` (emerald-700) | ยืนยัน (แบบเดียวกับเสร็จสิ้น) |
| ส่งกลับแก้ไข | `returned` | `#FFE4E6` (rose-100) | `#BE123C` (rose-700) | ภาพ |

ใช้ชื่อและสีชุดนี้ทุกหน้า รวมปฏิทินและรายงาน ปุ่มสำหรับส่งใช้คำว่า "ส่งตรวจ"

### สถานะบัญชีผู้ใช้

| สถานะ | พื้น | ตัวอักษร | ที่มา |
|---|---|---|---|
| ใช้งาน | `#D1FAE5` | `#047857` | ภาพ |
| ระงับการใช้งาน | `#FFE4E6` | `#BE123C` | ภาพ |

### ป้ายอื่น

| ป้าย | สีชุดเดียวกับ | ที่มา |
|---|---|---|
| ค้างตรวจ | ส่งกลับแก้ไข (ชมพูอ่อน) | ยืนยัน |
| ถูกลบ | ส่งกลับแก้ไข | ยืนยัน |
| กรอกเวลาเอง | รอตรวจ | ยืนยัน |
| แก้เวลาแล้ว | กำลังดำเนินการ | ยืนยัน |
| ตัวเลขแจ้งเตือน | พื้น danger ตัวอักษรขาว | ยืนยัน |

### บล็อกในปฏิทิน

พื้นอ่อนของชุดสีสถานะ มีแถบซ้ายสีตัวอักษรของสถานะนั้น "อนุมัติแล้ว" ใช้พื้น `#D1FAE5` แถบ success (ยืนยัน)

## 5. ปุ่ม

| ปุ่ม | พื้น | ตัวอักษร / ขอบ | ที่มา |
|---|---|---|---|
| เริ่มทำงาน ▶ | start | ขาว | ภาพ |
| ทำงานนี้เสร็จสิ้น ✓ | success | ขาว | รูปแบบตามภาพ ค่าสียืนยัน |
| ล็อก / กดไม่ได้ เช่น "ส่งตรวจ (ล็อก)" | line | `#94A3B8` (slate-400) | ภาพ |
| แก้ไข & ส่งตรวจใหม่ | ขาว | `#334155` ขอบ line | ภาพ |
| ปุ่มหลัก: สร้างรายการ ส่งตรวจ บันทึก อนุมัติ เข้าสู่ระบบ | primary (สีทึบ ไม่ไล่สี) | ขาว | ยืนยัน |
| ปุ่มรอง: บันทึกฉบับร่าง ยกเลิก ย้อนกลับ ดูรายละเอียด | ขาว | `#334155` ขอบ line | ยืนยัน |
| ดาวน์โหลด PDF / Excel | ขาว พร้อมไอคอนแยกชนิดไฟล์ | `#334155` ขอบ line | ยืนยัน |
| ส่งกลับแก้ไข | warning-action | ขาว | ยืนยัน |
| ลบ (ปุ่มยืนยันในหน้าต่าง) | danger | ขาว | ยืนยัน |
| ลบ (ปุ่มเปิดหน้าต่าง) | ขาว | danger ขอบ `#FECACA` (red-200) | ยืนยัน |

ในฟอร์มบันทึกงานทุกฟอร์ม **ส่งตรวจ** เป็นปุ่มหลัก และ **บันทึกฉบับร่าง** เป็นปุ่มรอง

ข้อความบนปุ่ม
- ปุ่มส่งตรวจที่ยังกดไม่ได้ในตารางใช้ "ส่งตรวจ (ล็อก)"
- ปุ่มเปิดดูใช้ "ดูรายละเอียด" ไม่ต่อท้ายด้วยคำในวงเล็บ

กติการ่วม (ยืนยัน)
- มุมโค้ง 8px ตัวอักษรหนา 600 ปุ่มหน้าเข้าสู่ระบบมุมโค้ง 12px และเต็มความกว้าง
- ตอนชี้เมาส์ใช้เฉดเข้มขึ้นหนึ่งระดับ ปุ่มขาวใช้พื้น page
- ปุ่มที่กดไม่ได้ใช้สีของแถว "ล็อก" ทุกชนิด และบอกเหตุผลด้วยข้อความใกล้ปุ่ม
- ระหว่างบันทึก เปลี่ยนข้อความเป็น "กำลัง..." และกดซ้ำไม่ได้
- หนึ่งกลุ่มปุ่มมีปุ่มหลักปุ่มเดียว

## 6. ส่วนประกอบอื่น (ยืนยัน)

| ส่วน | รูปแบบ |
|---|---|
| การ์ด | พื้นขาว ขอบ line มุมโค้ง 12px เงาบาง |
| ตาราง | หัวตารางพื้น page ตัวอักษรรอง เส้นคั่นแถว ตารางกว้างเลื่อนในกรอบของตัวเอง |
| ช่องกรอก | ขอบ line มุมโค้ง 8px ตอนกรอกขอบ primary ผิดพลาดขอบ `#F87171` พร้อมข้อความใต้ช่อง อ่านอย่างเดียวพื้น page |
| กล่องข้อความ | สำเร็จ พื้น `#ECFDF5` ตัวอักษร success, เตือน พื้น `#FFFBEB` ตัวอักษร `#B45309`, ผิดพลาด พื้น `#FEF2F2` ตัวอักษร `#B91C1C` |
| หน้าต่างยืนยัน | มุมโค้ง 12px ฉากหลังจาง ปุ่มยกเลิกอยู่ซ้ายของปุ่มยืนยัน ปุ่มยืนยันใช้สีของการกระทำนั้น |
| เมนูข้าง | กว้าง 180px จอแคบกว่า 1024px เปลี่ยนเป็นแถบบนกับเมนูเลื่อน |

## ข้อความแจ้งมุมจอ (ยืนยัน)

ทุกปุ่มที่ทำรายการ (บันทึก ส่ง ลบ อนุมัติ ส่งกลับ แนบไฟล์ ดาวน์โหลด เข้าและออกจากระบบ) ต้องแจ้งผลด้วยข้อความมุมจอ
ทั้งสำเร็จและไม่สำเร็จ ข้อผิดพลาดของฟอร์มแสดงค้างในฟอร์มด้วย
ปุ่มที่เปลี่ยนแค่สิ่งที่เห็นบนจอ เช่น แท็บ ตัวกรอง เลื่อนสัปดาห์ เปิดปิดเมนู ย้อนกลับ ไม่ต้องแจ้ง

| ชนิด | ใช้เมื่อ | สีวงกลมไอคอน |
|---|---|---|
| สำเร็จ | ข้อมูลถูกบันทึกหรือทำรายการเสร็จ | emerald อ่อน |
| แจ้งให้ทราบ | เปลี่ยนในหน้าจอแต่ยังไม่บันทึก | indigo อ่อน |
| ส่งกลับ | พี่เลี้ยงส่งกลับแก้ไข | warning-action |
| ผิดพลาด | ทำรายการไม่ได้ | red อ่อน |

## จุดที่โค้ดกำหนดค่า

| เรื่อง | ไฟล์ |
|---|---|
| token สี และคลาสปุ่ม `btn`, `btn-primary`, `btn-secondary`, `btn-start`, `btn-done`, `btn-sendback`, `btn-danger`, `btn-danger-outline` | `app/assets/css/main.css` |
| ชื่อและสีสถานะ | `app/utils/worklogStatus.ts`, `app/components/StatusBadge.vue` |
| สีบล็อกปฏิทิน | `app/utils/calendar.ts` |
| ข้อความแจ้งมุมจอ | `app/composables/useNotify.ts`, `app/composables/useFormNotice.ts` |
| รูปแบบวันที่ | `app/utils/date.ts` (`formatThaiDate` สำหรับแสดงผล, `formatThaiInputDate` สำหรับช่องกรอก) |

## ที่ไฟล์นี้ยังไม่ได้กำหนด

- แผงด้านซ้ายของหน้าเข้าสู่ระบบ ยังเป็นพื้นไล่สีเดิม
- แถบเลือกตัวกรองบนหน้าหลักใช้ primary แทนปุ่มที่เลือก และแถบสลับมุมมองปฏิทินใช้พื้นขาวตามเดิม
